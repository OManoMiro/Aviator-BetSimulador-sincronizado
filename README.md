Aviator Bet Simulador Sincronizado
Este é um simulador interativo desenvolvido com Streamlit para análise e previsão de multiplicadores com base em dados cronológicos reais. O objectivo é identificar padrões e picos futuros em sistemas de apostas estilo "Aviator" ou similares.
Funcionalidades: Interface simples e intuitiva; Entrada de dados em tempo real; Geração de gráficos e previsões; Identificação de padrões sincronizados.
